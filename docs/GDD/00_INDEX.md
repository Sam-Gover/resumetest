## Краткое описание

**CareerForge** — браузерная 3D-игра-резюме, превращающая профессиональный опыт системного архитектора в интерактивное пространство. Рекрутер или посетитель «проигрывает» ключевые навыки автора через головоломки и сценарии.

### Ключевые принципы
- **Data-Driven**: весь контент в JSON, код только интерпретирует
- **Модульная архитектура**: каждый модуль в отдельном файле
- **Масштабируемость**: добавление проекта = редактирование JSON
- **Играбельность**: реальные навыки → игровые механики

### Технологический стек
- Vite + TypeScript + React
- Three.js (3D-рендеринг)
- XState (управление состоянием)
- Zod (валидация данных)
- Tailwind CSS (UI)

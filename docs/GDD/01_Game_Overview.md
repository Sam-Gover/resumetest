# CareerForge v1.0 — Game Design Document

**Версия:** 1.0  
**Дата:** сентябрь 2026  
**Автор:** Самед Мусаев  
**Жанр:** интерактивное 3D-портфолио / кинематографичная мини-игра  
**Платформа:** браузер (WebGL)  
**Длительность:** 12–15 минут  
**Движок:** Three.js + TypeScript + Vite + React  

## Концепция

CareerForge — интерактивное 3D-резюме, упакованное в короткую сюжетную игру. HR за 12-15 минут проходит пять сцен — реальных рабочих кейсов автора.

**Главная идея:** «Не читай резюме — пройди его»

## Игровой цикл

```
Role Selector → Интро (облёт камерой, 6 сек)
      ↓
Туториал (3 подсказки, 5 сек)
      ↓
[ Сцена 1: Антифрод    ] → metric + score
[ Сцена 2: MVP         ] → metric + score
[ Сцена 3: Интеграция  ] → metric + score
[ Сцена 4: Портфель    ] → metric + score
[ Сцена 5: Bitrix24    ] → metric + score
      ↓
Финальный экран: ранг, очки, ачивки, метрики, CTA
```

## 5 сцен

### 1. Антифрод-система (Добро.рф)
- **Механика:** 12 карточек заявок, отклонить фрод (некорректный регион / дубликат ИНН)
- **Метрика:** −X% низкокачественных заявок
- **Максимум:** 200 очков

### 2. MVP за 2 месяца (ВОКСИС.ДОБРО)
- **Механика:** Квиз из 5 вопросов
- **Метрика:** MVP запущен: 20 сценариев, 80 требований, API с банком
- **Максимум:** 200 очков

### 3. API-интеграция (ВОКСИС.ДОБРО)
- **Механика:** Построить цепочку REST API из 4 узлов
- **Метрика:** Интеграция с Совкомбанком настроена
- **Максимум:** 200 очков

### 4. Портфель 9 проектов (РССМ)
- **Механика:** Распределить 9 проектов по 3 командам (лимит 6 млн ₽)
- **Метрика:** Экономия ~X млн ₽
- **Максимум:** 200 очков

### 5. Bitrix24 для 190 пользователей (Добро.рф)
- **Механика:** Обучить 10 регионов за 45 секунд
- **Метрика:** +X% скорость процессов
- **Максимум:** 200 очков

## Архитектура

```
/data/resume.json     — все данные (сцены, роли, достижения, контакты)
/src
  /audio              — AudioManager (Web Audio API)
  /director           — SceneDirector (рельсовая камера)
  /engine             — SceneManager, WorldGenerator
  /minigames          — 5 сцен + финал
  /onboarding         — RoleSelector, Tutorial
  /ui                 — GameHUD
  /types              — TypeScript типы
  App.tsx             — главный компонент
```

## Технологии

- **Vite** — сборка
- **TypeScript** — типизация
- **React** — UI
- **Three.js** — 3D-рендеринг
- **Web Audio API** — процедурный звук
- **Tailwind CSS** — стилизация

## Управление

- **ЛКМ / тап** — взаимодействие
- **Кнопка «Пропустить»** — всегда доступна
- **🔇/🔊** — звук вкл/выкл

Камера полностью автоматическая — рельсовый опыт.

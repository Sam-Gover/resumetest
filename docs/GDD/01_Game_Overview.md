# 01 — Game Overview

## Концепция

CareerForge — это интерактивное 3D-резюме, где профессиональный опыт превращён в играбельный мир. Вместо скучного PDF рекрутер получает пространство для исследования.

## Целевая аудитория

1. **Рекрутеры и HR** — оценивают навыки через геймплей
2. **Технические специалисты** — видят глубину компетенций
3. **Потенциальные клиенты** — понимают подход к работе
4. **Соискатели** — вдохновляются форматом

## Атмосфера

- **Визуальный стиль**: киберпанк-минимализм, неоновые акценты на тёмном фоне
- **Настроение**: технологичное, профессиональное, но дружелюбное
- **Музыка**: эмбиент-электроника (планируется)
- **Цветовая палитра**: тёмно-синий фон (#0a0a2e), cyan-акценты (#00ffff), тёплые цвета для зданий

## Ключевые особенности

### 1. Data-Driven мир
Весь контент хранится в `data/resume.json`. Добавление нового проекта — это добавление записи в JSON. Код автоматически генерирует здание, сценарий и привязанные способности.

### 2. Способности = Навыки
Каждая игровая способность — это реальный навык из резюме:
- Сканер требований → бизнес-анализ
- AI-Ассистент → AI-assisted development
- API-Портал → REST API интеграции
- и т.д.

### 3. Сценарии из реального опыта
Каждый проект из резюме становится мини-игрой:
- Добро.рф → антифрод-система
- ВОКСИС.ДОБРО → запуск MVP
- РССМ → управление портфелем
- Банк ПСБ → Scrum-цикл

### 4. Метрики эффективности
После прохождения сценария игрок видит реальные метрики из резюме (89 регионов, 9 млн пользователей и т.д.)

## Игровой цикл

```
Hub → Выбор здания → Телепортация → Сценарий → Применение способностей → Завершение → Награда (метрики) → Hub
```

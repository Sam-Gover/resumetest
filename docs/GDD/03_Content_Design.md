# 03 — Content Design

## Структура мира

Мир CareerForge — цифровой город, разделённый на 3 квартала + центральный HUB.

### HUB (Центральная площадь)
- **Координаты**: (0, 0, 0)
- **Функция**: стартовая точка, навигация, портал к зданиям
- **Визуал**: круглая платформа с неоновым кольцом-порталом
- **NPC**: Архитектор-Навигатор (подсказки по управлению)

### Квартал проектов
- **Центр**: (0, 0, -20)
- **Содержимое**: здания-проекты из work[]
- **Цвет**: тёмно-синий (#1a1a4e)
- **Здания**:
  - ВОКСИС.ДОБРО — (-20, 0, -15), синяя тема
  - Добро.рф — (20, 0, -15), зелёная тема
  - РССМ — (0, 0, -30), фиолетовая тема
  - Банк ПСБ — (-20, 0, 15), оранжевая тема

### Квартал технологий
- **Центр**: (25, 0, 10)
- **Содержимое**: интерактивные объекты API, AI, тестирование
- **Цвет**: тёмно-голубой (#0a2a4e)
- **NPC**: Технический Ментор

### Квартал стратегии
- **Центр**: (-25, 0, 10)
- **Содержимое**: управление проектами, KPI, бюджеты
- **Цвет**: тёмно-фиолетовый (#2a0a4e)

## Генерация зданий

Каждое здание генерируется из записи work[] в resume.json:

```
worldPosition → позиция в мире
buildingTheme → цвет (blue/green/purple/orange/red/cyan)
buildingScale → размер (x, y, z)
name → текстовая метка над зданием
position → подпись должности
```

### Визуальные элементы здания
1. **Корпус** — BoxGeometry с metallic-материалом
2. **Окна** — светящиеся плоскости на фасадах
3. **Антенна** — цилиндр на крыше
4. **Маяк** — светящаяся сфера (пульсирует)
5. **Платформа** — светящийся цилиндр у основания
6. **Метка имени** — Canvas-текстура над зданием

## NPC и диалоги

NPC загружаются из `data/dialogues.json`:

### Архитектор-Навигатор
- **Локация**: HUB
- **Функция**: обучение, подсказки
- **Дерево диалогов**: start → about_projects / about_abilities / about_controls → end

### Технический Ментор
- **Локация**: Квартал технологий
- **Функция**: объяснение механик API, AI
- **Дерево диалогов**: start → api_demo / ai_demo → end

## Data-Driven генерация

### Алгоритм генерации мира
```
1. Загрузить resume.json
2. Валидировать по схеме
3. Создать ground + grid
4. Для каждого district → создать маркер + метку
5. Для каждого work[] → создать здание
6. Создать HUB-портал
7. Создать частицы-звёзды
8. Добавить освещение
```

### Добавление нового контента

**Новый проект:**
```json
{
  "id": "new-project",
  "name": "Название",
  "position": "Должность",
  "summary": "Описание",
  "worldPosition": { "x": 30, "y": 0, "z": 5 },
  "buildingTheme": "cyan",
  "buildingScale": { "x": 6, "y": 8, "z": 6 },
  "scenario": { ... }
}
```
→ Здание автоматически появится в мире.

**Новый навык:**
```json
{
  "id": "new_skill",
  "name": "Название навыка",
  "level": 85,
  "category": "technical",
  "abilityMapping": "existing_ability_id"
}
```
→ Навык появится в инвентаре.

**Новая способность:**
```json
{
  "id": "new_ability",
  "name": "Название",
  "description": "Описание",
  "icon": "🎯",
  "hotkey": "8",
  "cooldown": 10,
  "duration": 15,
  "color": "#ff00ff"
}
```
→ Способность появится в панели + нужно добавить визуальный эффект в AbilitySystem.

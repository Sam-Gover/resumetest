### 🔄 Как обновить данные

Если нужно изменить резюме:

1. Откройте `data/resume.json`
2. Измените нужные поля
3. Сохраните файл
4. Перезапустите `npm run dev`

**Важно:** не меняйте код — только JSON!

#### Добавить новый проект:

```json
{
  "id": "new-project",
  "name": "Название компании",
  "position": "Ваша должность",
  "startDate": "2026-09-01",
  "endDate": "2026-12-01",
  "summary": "Описание",
  "highlights": ["Достижение 1", "Достижение 2"],
  "metrics": { "metric1": "value1" },
  "worldPosition": { "x": 30, "y": 0, "z": 10 },
  "buildingTheme": "cyan",
  "buildingScale": { "x": 6, "y": 8, "z": 6 },
  "scenario": {
    "title": "Название сценария",
    "description": "Что нужно сделать",
    "abilities": ["ability_id_1", "ability_id_2"],
    "steps": [
      { "id": "step1", "text": "Шаг 1", "type": "collect" },
      { "id": "step2", "text": "Шаг 2", "type": "launch" }
    ]
  }
}
```

#### Добавить новый навык:

```json
{
  "id": "new_skill",
  "name": "Название навыка",
  "level": 85,
  "category": "technical",
  "abilityMapping": "ai_assistant"
}
```

Категории: `analysis`, `technical`, `ai`, `management`, `quality`, `systems`, `tools`, `soft`

### 📁 Структура проекта

```
/data
  resume.json          ← ВАШЕ РЕЗЮМЕ (редактируйте здесь!)
  dialogues.json       ← NPC и диалоги
/schemas
  resume_schema.json   ← JSON Schema для валидации
/src
  engine/              ← 3D-движок (Three.js)
  state/               ← XState машина состояний
  ui/                  ← React UI компоненты
  types/               ← TypeScript типы
/docs/GDD/             ← Гейм-дизайн документы
```

### 🎯 Ключевые особенности

✅ **Data-Driven** — весь контент в JSON, код только интерпретирует
✅ **Модульная архитектура** — каждый модуль в отдельном файле
✅ **Масштабируемость** — добавление проекта = редактирование JSON
✅ **Играбельность** — реальные навыки → игровые механики
✅ **Профессионально** — все метрики и факты из реального резюме
✅ **Интерактивно** — 3D-мир, способности, сценарии, NPC

# 🚀 Как запустить CareerForge

## Проблема
Папка `dist/` со собранной игрой не попадает в архив, потому что создаётся только при сборке.

## Решение

### Вариант 1: Запустить через Node.js (рекомендуется)

1. **Установите Node.js** (если ещё не установлен):
   - Скачайте с https://nodejs.org/
   - Установите версию LTS (Long Term Support)

2. **Откройте терминал в папке проекта**:
   - В VS Code: `Ctrl + ~` (откроется терминал)
   - Или откройте командную строку (cmd) и перейдите в папку проекта

3. **Установите зависимости**:
   ```bash
   npm install
   ```

4. **Запустите dev-сервер**:
   ```bash
   npm run dev
   ```

5. **Откройте в браузере**:
   - Перейдите по адресу: http://localhost:3000
   - Или нажмите `Ctrl + Click` на ссылку в терминале

### Вариант 2: Собрать и открыть как файл

1. **Выполните шаги 1-3 из Варианта 1**

2. **Соберите проект**:
   ```bash
   npm run build
   ```

3. **Откройте файл**:
   - Перейдите в папку `dist/`
   - Откройте файл `index.html` двойным кликом
   - Он откроется в браузере и будет работать автономно

### Вариант 3: Использовать Python (если установлен)

1. **Откройте терминал в папке проекта**

2. **Запустите простой HTTP-сервер**:
   ```bash
   # Python 3
   python -m http.server 3000
   
   # Или Python 2
   python -m SimpleHTTPServer 3000
   ```

3. **Откройте в браузере**:
   - Перейдите по адресу: http://localhost:3000

## Требования

- **Node.js** версии 18 или выше
- **Современный браузер** с поддержкой WebGL (Chrome, Firefox, Edge, Safari)
- **Минимум 2 GB RAM**

## Решение проблем

### Ошибка "Cannot find module"
```bash
npm install
```

### Ошибка "Port 3000 is already in use"
```bash
# Используйте другой порт
npm run dev -- --port 3001
```

### Чёрный экран в браузере
- Проверьте консоль браузера (F12) на наличие ошибок
- Убедитесь, что WebGL поддерживается
- Попробуйте другой браузер

### Ошибка CORS при открытии файла
- Используйте один из вариантов запуска выше
- Не открывайте `index.html` напрямую из папки `dist/`

## Контакты

Если возникли проблемы, проверьте:
1. Версию Node.js: `node --version` (должна быть 18+)
2. Наличие папки `node_modules/` (должна появиться после `npm install`)
3. Консоль браузера (F12) на наличие ошибок JavaScript

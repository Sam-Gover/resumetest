# CareerForge: The System Architect's Journey

> Интерактивное 3D-резюме. Не читай резюме — пройди его.

**Жанр:** кинематографичная мини-игра  
**Длительность:** 12-15 минут  
**Платформа:** браузер (WebGL)

## 🎮 Что это?

CareerForge превращает резюме бизнес-системного аналитика в 5 интерактивных сцен:

1. **🛡️ Антифрод** — отсортируйте заявки, выявите фрод
2. **💡 MVP за 2 месяца** — квиз по запуску платформы
3. **🔌 API-интеграция** — постройте цепочку REST API
4. **📊 Портфель проектов** — распределите 9 проектов по командам
5. **🚀 Bitrix24** — обучите 10 регионов за 45 секунд

Каждая сцена — реальный кейс из резюме. В конце — ранг (S/A/B/C), очки, ачивки и контакты.

## 📁 Структура

```
/data/resume.json     — все данные (data-driven)
/src
  /audio              — AudioManager (Web Audio API)
  /director           — SceneDirector (рельсовая камера)
  /engine             — Three.js сцена
  /minigames          — 5 сцен + финал
  /onboarding         — выбор роли, туториал
  /ui                 — HUD
  App.tsx             — главный компонент
```

## ✏️ Как обновить резюме

Откройте `data/resume.json` и измените данные. Код не трогайте!

### Добавить новую сцену:
1. Создайте компонент в `src/minigames/`
2. Добавьте в `data/resume.json` → `scenes`
3. Подключите в `App.tsx`

### Изменить контакты:
Отредактируйте `basics.contacts` в `data/resume.json`.
